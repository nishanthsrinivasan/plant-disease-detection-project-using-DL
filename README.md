# Plant Disease Detection using Deep Learning

This project detects plant diseases using a CNN model trained on the PlantVillage dataset.

## Technologies
- Python
- TensorFlow
- Keras
- Google Colab

## Files
train_model.ipynb → model training notebook  
plant_model.keras → trained model  

## How to Run
1. Open the notebook in Google Colab
2. Load the model
3. Upload a plant image
4. Run prediction
