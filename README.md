# 🌿 Plant Disease Detection using Deep Learning

This project detects plant diseases from leaf images using a Convolutional Neural Network (CNN) trained on the PlantVillage dataset.
The model can classify plant leaves into healthy or diseased categories and identify the specific disease.

---

## 📌 Project Overview

Plant diseases can significantly affect crop yield and food production.
This project uses **Deep Learning and Computer Vision** to automatically detect plant diseases from leaf images.

The model was trained using the **PlantVillage dataset** and implemented using **TensorFlow/Keras**.
